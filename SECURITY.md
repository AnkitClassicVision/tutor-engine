# Security policy

This app holds children's data, so security reports get priority.

## Reporting a vulnerability

Please **do not open a public issue.** Use GitHub's private reporting instead: the **Security** tab → **Report a vulnerability**. Include what you found, how to reproduce it, and what an attacker could reach. We aim to acknowledge reports within 3 days and to agree a fix and disclosure date with you.

Please test only against your own local or self-hosted copy. Don't test the public demo with other families' accounts, automated scanning or denial-of-service traffic, and never access or keep data that isn't yours.

## Supported versions

Fixes land on `main`. Self-hosters should update and redeploy; see [docs/SELF-HOSTING.md](docs/SELF-HOSTING.md).
