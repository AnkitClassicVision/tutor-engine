# Code of conduct

This project serves children and families, and we want everyone who contributes to feel welcome. We follow the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and patient, assume good intent, critique ideas and not people, and never harass anyone. Take extra care with anything involving children: never post a real child's name, work, photo or data in issues, pull requests or test files.

Report unacceptable behaviour privately to the maintainers through GitHub (a private security advisory works if nothing else fits). Reports are handled confidentially.
