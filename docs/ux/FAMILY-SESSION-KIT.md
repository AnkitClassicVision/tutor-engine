# Family session kit

A short, repeatable way for a parent to watch their own children use the tutor and write down what happens. It covers the interface independence, parent clarity and healthy completion panels in [QA-SCORECARD.md](QA-SCORECARD.md), plus the retention follow-ups. It is an informal family check, not a research study: one family cannot establish usability for everyone or learning effectiveness.

Keep every filled-in sheet, note, photo and recording **outside this repository**. Use first names or initials only on paper. Nothing in this kit is sent anywhere.

## Before you start (5 minutes)

- Use the live site or the local copy. Pick the device the child normally uses: phone, tablet or laptop. Note which.
- Make sure the parent area is locked ("Lock and return to student mode").
- Ask the child, in your own words: "I'm checking whether the tutor is easy to use. You're not being tested. If something is confusing, that's the tutor's fault, not yours. You can stop any time." Stop if they want to.
- Sit beside them, not in front of the screen. Don't point at anything unless they are stuck for a full minute or ask for help. If you help, say what you said and tally it below.

## Child tasks (15–20 minutes)

Say each task once, as written. Don't name buttons.

| # | Say this | It works if the child… | Relevant step |
|---|---|---|---|
| C1 | "Start today's practice." | reaches a question without help | WF-02 |
| C2 | "Answer this one however you think." | submits an answer | WF-03 |
| C3 | (After a miss) "What does the tutor think?" | finds and understands the feedback; ages 5–7 can hear it | Step 6 |
| C4 | "If you think the tutor got it wrong, can you tell it?" | finds "I think there's a mistake" (only if a miss looked wrong to them) | Step 5 |
| C5 | "Ask the tutor a question about this." | types or says a question and sends it | Step 2 |
| C6 | "Stop for now so you can come back later." | uses Save & stop, and later finds "Pick up where I left off" | WF-08 |
| C7 | (At the end of a mission) "You're done. What do you do now?" | chooses Done for today without being pushed to continue | Step 6 |
| C8 | (Ages 5–7) "Show me a page of homework." | takes a photo without filling in a form | Step 6 |
| C9 | (At the end) "What is the tutor? Can it be wrong?" | Write down their words; there is no right answer | Research Q4 |

## Observation sheet (copy one per child)

```
Date:            Child (initials):      Age band: 5–7 / 8–10 / 11–14
Device:          phone / tablet / laptop     Browser:
Input:           touch / keyboard / voice    Read aloud on? yes / no

Task  Done alone?  Navigation help (count)  Teaching help (count)  Notes (what they said or did)
C1    Y / N
C2    Y / N
C3    Y / N
C4    Y / N / n.a.
C5    Y / N
C6    Y / N
C7    Y / N
C8    Y / N / n.a.
C9    (their words):

Navigation help = you explained the screen or a button.
Teaching help   = you explained the maths, reading or idea.
Ended by: Done for today / Save & stop / gave up / technical problem
Anything that broke (page, message, lost work):
```

Count navigation and teaching help separately. A wrong answer does not make a task fail; you pointing to the Check button does.

## Parent tasks (10 minutes, after the child)

Unlock the parent area. Without looking at this list again, answer from the screen:

| # | Question | Correct if you can say… |
|---|---|---|
| P1 | What happened this week? | missions, topics, how it went |
| P2 | What did they do on their own, and what with help? | independent versus supported work |
| P3 | What is the tutor unsure about? | any banner about unsure grades or a child's concern, and where to decide |
| P4 | What needs you next? | the one "Needs you" line |
| P5 | Switch a feature comparison on, then lock the parent area again. | done without help |
| P6 | What works without an AI connection? | the shared statement in AI settings |

Write "can't tell" when you can't. That is useful information.

## Follow-ups

Retention is checked on the tutor's own schedule. Note the date of each topic's first "solved on their own" in the numbers page, then look again at **7–9 days** and **28–32 days** after that date: did the ladder step "remembered after a week / a month" fill in, and was it with help? Missed days are fine; do not schedule extra practice to make it happen.

## After each session

Write down the three most confusing moments, with the task number and device. Bring them back to the plan as the next work card. Don't change anything mid-session. Repeat the same tasks on a different device or another child before calling something fixed.
