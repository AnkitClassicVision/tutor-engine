# WF-09 Export, deletion and shared devices

## Current behaviour (code)

- **Export** (`src/accounts.ts` export) carries the learning record without hashes, tokens or storage paths (`test/hardening.test.ts:500`).
- **Deletion** (`deleteFamily`) erases sealed data and private files, and keeps trying through storage failures (`test/family-crypto.test.ts:63,99`, `test/hardening.test.ts:251,271`).
- **Lock and logout:** parent lock, logout and student mode (`test/hardening.test.ts:73`, `test/journey-http.test.ts:83`).
- **Drafts:** child drafts are stored per path in session storage (round 1, step 2), so they stay in the tab after logout.

## Proposed contract

**Trigger:** an authorized parent asks to export or delete, or ends a shared-device session. **Exit:** the file is downloaded, the deletion is confirmed or cancelled, or the next user sees the sign-in page.

| State | Wording | Action | Effect |
|---|---|---|---|
| `export_ready` | "Download your family's learning record" | Download | File generated on request |
| `confirm_delete` | Names exactly what is removed (children, work, photos, connections) and that it cannot be undone | Type the confirmation, then Delete | Deletion as implemented |
| `deleting` | "Deleting… this can take a minute for photos." | none | Existing erasure manifest |
| `logged_out` | Sign-in page | none | Session ended; session drafts cleared |

**Small proposal:** on logout and on locking to student mode, clear session-storage drafts for paths outside the selected child. The browser back button after logout should show the sign-in page, not a cached parent page. Check whether the `Cache-Control: no-store` header is set on parent pages; add it if missing.

**Engine-rule diff:** none.

## Acceptance cases (WF-09-A)

1. An export request for another family's child is refused. HTTP test.
2. Cancelling at the deletion confirmation changes nothing.
3. A partial storage failure shows its true status (existing).
4. After logout, Back does not show parent data. Browser test.
5. A sibling never sees another child's draft after switching (round 1, step 2, by path; extend to logout).
